🧮 MATHEMATICAL FOUNDATION:

Core Formula (Bayes Theorem):
P(Result | Evidence) = [P(Evidence | Result) × P(Result)] / P(Evidence)

In Simple Terms:
"What's the probability of getting 'Excellent' given that you have:
- High study hours
- High attendance  
- Active participation"

STEP-BY-STEP CALCULATION EXAMPLE:
1. P(Excellent) = 3/6 = 0.5 (50% of students are excellent)
2. P(High Study | Excellent) = 2/3 ≈ 0.67
3. P(High Attendance | Excellent) = 1/3 ≈ 0.33
4. P(Active Participation | Excellent) = 2/3 ≈ 0.67

FINAL SCORE = 0.5 × 0.67 × 0.33 × 0.67 ≈ 0.074

The algorithm does this for ALL possible outcomes and picks the highest score!
